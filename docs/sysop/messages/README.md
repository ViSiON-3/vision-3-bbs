# Messages

Set up and manage message areas, private mail, offline (QWK) mail, echomail
networking, V3Net, and the `v3mail` utility.

- **[Message Areas](messages/message-areas.md)** — configuring JAM message bases, area settings, the reader and editor
- **[Private Mail](messages/private-mail.md)** — user-to-user private messaging
- **[Twit Filter List](messages/twit-list.md)** — personal author filters, security exemptions, and reader shortcuts
- **[Auto-Signature](messages/autosig.md)** — per-user signatures, with an optional ask-before-each-post
- **[QWK Offline Mail](messages/qwk.md)** — packet download and reply upload for callers
- **[QWK Packet API (experimental)](messages/qwk-api.md)** — the same packets over HTTPS for the mobile client
- **[QWK Networking (QWKnet)](messages/qwk-networking.md)** — joining a QWK-based network such as DOVE-Net
- **[FTN Echomail](messages/ftn-echomail.md)** — FTN network setup, node configuration, tossing
- **[FTN Nodelists](messages/nodelists.md)** — compiling nodelists and looking systems up
- **[JAM Echomail](messages/jam-echomail.md)** — echomail in JAM message bases
- **[V3Net Networking](v3net/message-areas.md)** — native inter-BBS message networking via REST+SSE
- **[V3Mail](messages/v3mail.md)** — the `v3mail` message base and mail utility
- **[Header Placeholders](messages/placeholders.md)** — MSGHDR.* template tokens
