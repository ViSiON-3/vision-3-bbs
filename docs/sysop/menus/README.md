- **[Customising without losing changes](menus/menu-system.md#customising-menus-without-losing-your-changes)** — the `menus.d/` overlay that survives upgrades
- **[News](menus/news.md)**, **[BBS Listings](menus/bbs-list.md)**, **[Rumors](menus/rumors.md)**, **[InfoForms](menus/infoforms.md)** — the community features the shipped menus hang off the main menu
